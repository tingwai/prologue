Configure your extension to get AI-powered code explanations on GitHub pull requests

💡 How it works

This extension analyzes GitHub PR diffs using Claude AI. When you select any code snippet in a pull request, you'll get instant explanations and context.

  • PRs are cached per commit for fast responses
  • Private repository support with GitHub token
  • Concise, insightful explanations (not verbose)
Get your API key from console.anthropic.com
Required for private repositories. Create a classic token at github.com/settings/tokens with repo scope.
